# Тренировка — план приложения (PWA)

## Идея
Личное приложение-тренер в формате **PWA**: анкета → персональный план тренировок + дневник калорий + встроенная база знаний + чат-советник. Работает офлайн, данные в браузере (localStorage).

**Установка на iPhone:** сайт выкладывается в интернет (GitHub Pages / Netlify, бесплатно) → в Safari «Поделиться» → «На экран “Домой”» → иконка, полный экран, офлайн. Без App Store и аккаунта разработчика.

---

## Функции V1

1. **Анкета/профиль** — пол, возраст, рост, вес, цель (похудение / масса / форма), уровень, дней в неделю, место (зал/дом), инвентарь, ограничения (спина/колени/плечи).
2. **Генератор тренировок** — недельный план: дни → группы мышц → упражнения с подходами/повторами/отдыхом и техникой. Прогрессия на 4 недели.
3. **Дневник калорий** — база продуктов (ккал/Б/Ж/У на 100 г, ~100 позиций), приёмы пищи по секциям, итого за день против нормы.
4. **Нормы питания** — BMR (Миффлин-Сан Жеор) → TDEE → коррекция под цель → БЖУ (белок/жиры/углеводы по весу). Подсказки меню по приёмам пищи.
5. **База знаний** — ~20 статей: техника упражнений, принципы (прогрессия, стагнация, дефицит), питание до/после, сон, вода, боли в спине/коленях/плечах. С поиском и фильтрами.
6. **Тренер-советник («мини-ИИ»)** — чат: отвечает на вопросы, опираясь на базу знаний + твои данные (нормы, план, дневник). Работает офлайн на правилах эксперта + поиск по базе знаний.
7. **Экран «Сегодня»** — сводка: калории, вода, тренировка дня, совет тренера, отметки «выполнено».
8. **PWA** — манифест + service worker: иконка на iPhone, офлайн-режим.

⚠️ Все расчёты — усредненные рекомендации, не медицинский совет (дисклеймер в приложении).

---

## Архитектура

**Стек:** чистый HTML + CSS + JS, без фреймворков и сборки. Хостинг: GitHub Pages / Netlify (бесплатный HTTPS — нужен для установки на iPhone).

**Структура:**
```
тренировка/
  index.html          — каркас экранов и вкладок
  manifest.json       — имя/иконки для установки
  sw.js               — офлайн-кэш
  icone/              — иконки 192/512
  css/style.css
  js/
    data-exercises.js — база упражнений (~50: мышца, инвентарь, уровень, техника)
    data-foods.js     — база продуктов + шаблоны меню
    knowledge.js      — база знаний (статьи, теги)
    profile.js        — профиль (анкета, localStorage)
    planner.js        — генератор планов тренировок
    nutrition.js      — нормы/БЖУ/меню + дневник калорий
    coach.js          — мини-ИИ: чат, интенты, советы (rule-based + поиск по базе знаний)
    app.js            — вкладки,状态, рендер, модалки
```

**Данные в localStorage:** профиль, план, отметки выполнения, дневник по дням, чат.

## Логика генератора

1. **Сплит:** 2 дн → Full Body A/B; 3 → Full Body (новичок) или Push/Pull/Legs; 4 → Верх/Низ ×2; 5 → PPL+Верх/Низ; 6 → PPL ×2.
2. **Подбор упражнений:** фильтр по группе мышц + инвентарю (зал = всё; дом = по выбранному инвентарю) + уровню + исключение упражнений с метками травм (спина/колени/плечи).
3. **Схема по цели:** похудение 3×12–20 (отдых 45–60с), масса 4×8–12 (60–90с), форма 3×10–15 (60с). Новичку — меньше объёма, только базовые.
4. **Прогрессия 4 недели:** техника → +повторы → +вес 2.5% → разгрузка.

## Логика питания

BMR по Миффлину → TDEE по активности (дни тренировок) → дефицит −18% / профицит +12% / поддержка → белок 1.6–2.2 г/кг, жиры ~1 г/кг, углеводы — остаток. Меню — шаблоны приёмов из базы продуктов (варианты под цель).

## Мини-ИИ (rule-based)

- **Интенты** («сколько мне калорий», «болит спина», «как прогрессировать»…): отвечают из твоих данных или базы знаний.
- **Поиск по базе знаний:** если прямого интента нет, ищем статью по ключевым словам и отвечаем ею.
- **Совет дня:** на основе дневника (не заполнен / дефицит / перебор) и отметки тренировки.
- В V2/V3 можно подключить настоящий LLM (API-ключ) — архитектуре чата это не мешает.

## Как поставить на iPhone
1. Выложить папку на GitHub Pages (нужен аккаунт GitHub — могу помочь) или Netlify Drop.
2. Открыть ссылку в Safari → «Поделиться» → «На экран “Домой”».
3. Готово: иконка работает как приложение, даже без интернета.

## Риски/трудности
- Наполнение баз (упражнения/продукты/статьи) — ручная работа, самая долгая часть.
- Меню — усреднённые шаблоны, не точный подбор «в каждый грамм».
- Установка на iPhone требует HTTPS-хостинга (файл с диска не поставить).
